# 在 WorkBuddy 中使用同花顺

安装同花顺 Agent 后，你可以在 WorkBuddy 中查询行情和 K 线、查看持仓、接收
实时数据并使用盯盘功能。

## 安装

1. 在仓库根目录运行 `Build-Distribution.ps1` 生成 WorkBuddy 安装包。
2. 在 WorkBuddy 的插件管理页面导入安装包。
3. 安装完成后重启 WorkBuddy。
4. 首次使用时运行 `configure-ths`，按提示选择同花顺安装目录。
5. 配置完成后重启同花顺。

## 开始使用

可以直接询问证券行情、K 线、账户持仓或实时盯盘信息。交易工具默认关闭；
启用后，下单、撤单和改单仍需用户确认。

本项目不是同花顺官方产品。
