# tonghuasun-agent 架构

## 运行方式

Codex、Claude Code、WorkBuddy、ZCode、OpenClaw 和 DeepSeek Harness 使用各自的插件入口，通过本机 MCP 连接
同一个同花顺服务。

```text
Codex ────────────────┐
Claude Code ───────────┤
WorkBuddy ────────────┼─ MCP 传输桥 ─ 本机同花顺服务 ─ 同花顺
ZCode ────────────────┤
OpenClaw ─────────────┤
DeepSeek Harness ─────┘
```

行情、账户和交易能力由本机同花顺服务提供。六个 Agent 插件只负责安装、配置和
连接，不各自维护证券业务接口。

## 仓库目录

```text
tonghuasun-agent/
  codex/               Codex 插件清单
  claude-code/         Claude Code 插件清单
  workbuddy/           WorkBuddy 插件清单
  zcode/               ZCode 插件清单
  openclaw/            OpenClaw Agent Plugins 清单
  deepseek-harness/    DeepSeek Harness 插件清单
  tonghuasun-mcp/
    tooling/           配置器、传输桥和界面构建工具
    distribution/      公共发行文件
    legal/             许可证和法律声明
```

C# 开发的同花顺本机插件暂时闭源，发行版以已编译组件提供。

## 本机连接

同花顺服务默认监听 `127.0.0.1:17180`。配置器会生成随机访问令牌，并把端口、
令牌和运行时地址保存在 `%LOCALAPPDATA%\TonghuasunCodex`。

MCP、REST 和 WebSocket 使用同一套数据与权限检查。Python SDK 读取相同的运行时
配置，因此无需在代码中写死端口或访问令牌。

## 更新和卸载

更新、修复或卸载本机插件前，应先正常退出同花顺。配置器只处理由本项目安装并能
确认归属的文件，不删除其他同花顺文件。

## 交易安全

交易工具默认关闭。启用后，交易请求先生成预览，确认时不能修改原始证券代码、
价格、数量或账户。下单、撤单和改单还需要同花顺桌面确认。无人值守 REST 交易
使用独立开关，不会因为启用 Agent 交易工具而自动开启。
