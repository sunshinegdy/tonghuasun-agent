# tonghuasun-agent 0.3.0 架构

## 运行链路

```text
Codex ── stdio MCP 代理 ─┐
                         ├─ Node 本机行情服务 ─ HTTPS ─ iFinD HTTP API
Python SDK ─── REST ─────┘
```

本机服务监听 `127.0.0.1:17180`，同时提供 Streamable HTTP MCP 和固定 REST 接口。Codex 代理把 stdio MCP 透明转发到该端点；Python SDK 读取同一份本机配置并访问 REST。

## 组件

- `tooling/src/ifindClient.ts`：iFinD 鉴权、限速、重试与响应展开。
- `tooling/src/securityResolver.ts`：证券目录、主要指数别名和名称歧义处理。
- `tooling/src/marketService.ts`：实时行情、K 线、复权、窗口和缓存。
- `tooling/src/httpServer.ts`：REST 与 MCP 服务入口。
- `tooling/src/installer.ts`：Keychain、LaunchAgent、版本化安装和卸载。
- `distribution/sdk/python`：本机 REST Python SDK。

## 配置与凭据

```text
~/Library/Application Support/TonghuasunAgent/
├── config.json                 本机随机访问令牌、端口、Node 与版本路径
├── runtime/endpoint.json       当前进程和端点
├── releases/0.3.0/             版本化服务文件
└── cache/security-master.json  证券目录和 ETF 名称缓存
```

iFinD refresh token 只存储在 macOS Keychain 的 `com.tonghuasun-agent.ifind.refresh-token` 项中。服务日志不得记录 refresh token、access token 或本机访问令牌。

## 数据边界

- 快照缓存 2 秒。
- 当前 K 线缓存 30 秒。
- 明确结束于历史日期的 K 线缓存 24 小时。
- A 股证券目录缓存 24 小时；基金名称回退缓存 30 天。
- 不在网络错误时静默返回过期行情。

## 安全边界

- 上游只允许 `https://quantapi.51ifind.com`。
- 本机服务只监听 IPv4 回环地址。
- MCP 与行情 REST 请求必须携带随机本机令牌。
- 行情能力完全只读，不注册账户或交易工具。
