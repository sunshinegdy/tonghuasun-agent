# 在 ZCode 中使用同花顺

## 安装

1. 在仓库根目录运行 `Build-Distribution.ps1`。
2. 解压 `artifacts/tonghuasun-agent-zcode-marketplace-<版本>.zip`。
3. 在 ZCode 左侧进入“插件市场”。
4. 点击“新建 -> 添加插件市场”，选择解压后的市场根目录。
   该目录下应直接存在 `.claude-plugin/marketplace.json`。
5. 在“个人”分段安装并启用“同花顺 Agent”。

首次使用前先正常退出同花顺，再让 ZCode“配置同花顺插件”。配置完成后启动
同花顺，并在“设置 -> MCP”的“Plugin MCP 服务器”中确认服务已经连接。

## 开始使用

可以直接这样提问：

- `查看贵州茅台最近 60 个交易日的日 K 线。`
- `汇总我的账户资产和持仓。`
- `持续盯盘 600519.SH 的逐笔成交。`

交易工具默认关闭。启用后，下单、撤单和改单仍需用户确认。

本项目不是同花顺官方产品。
